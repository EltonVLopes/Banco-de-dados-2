# 📚 Aula 28/10

## 📖 Conteúdo

Nesta aula foi realizada uma revisão dos comandos DCL (Data Control Language), utilizados para criação de usuários e gerenciamento de permissões de acesso ao banco de dados.

Também foram estudados índices (INDEX), sua criação e utilização para melhorar o desempenho das consultas SQL, além de Stored Procedures (procedimentos armazenados), utilizadas para executar conjuntos de comandos SQL.

## 📝 Atividades

Foram realizados exercícios envolvendo criação de usuários, concessão e revogação de permissões com GRANT e REVOKE.

Também foram praticadas a criação e consulta de índices, com comparação do desempenho das consultas antes e depois da implementação de um índice. Por fim, foi criada e executada uma Stored Procedure utilizando CREATE PROCEDURE e CALL para realizar consultas em diferentes tabelas.
