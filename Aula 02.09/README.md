# 📚 Aula 02/09

## 📖 Conteúdo

Nesta aula foram apresentados os conceitos de **backup e restore de banco de dados**, abordando formas de realizar cópias de segurança e restaurar um banco de dados.

Também foram apresentados os **comandos de restrições em SQL**, utilizados para definir regras e garantir a integridade dos dados no banco de dados.
