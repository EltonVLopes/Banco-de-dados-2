# 📚 Aula 04/11

## 📖 Conteúdo

Nesta aula foi realizada uma revisão e um aprofundamento sobre índices (INDEX) e Stored Procedures (procedimentos armazenados) em SQL.

Foram estudados comandos para consultar, criar e excluir índices, além da análise do plano de execução para verificar o desempenho das consultas antes e depois da criação de novos índices.

Também foram trabalhadas Stored Procedures sem parâmetros e com parâmetros, utilizando CREATE PROCEDURE, CALL e comandos de manipulação de dados.

## 📝 Atividades

Foram realizados exercícios de criação de índices nas tabelas de funcionários, gêneros, editoras e livros, comparando o custo das consultas antes e depois da implementação dos índices.

Também foram desenvolvidas Stored Procedures para consultar dados de clientes, pedidos, veículos e vendedores, além de procedimentos para listar informações de pedidos e inserir novos vendedores utilizando parâmetros.
