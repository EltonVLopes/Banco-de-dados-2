# 📚 Aula 26/08

## 📖 Conteúdo

Nesta aula foram apresentados **comandos básicos de SQL**, incluindo a criação e utilização de bancos de dados, criação de tabelas e definição de relacionamentos entre elas.

Também foi apresentado o conceito de **população de banco de dados**, utilizando comandos para inserir dados nas tabelas.

Foram realizados exercícios práticos para aplicar e reforçar os comandos de SQL apresentados durante a aula.
