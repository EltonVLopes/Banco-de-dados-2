# 📚 Aula 21/10

## 📖 Conteúdo

Nesta aula foi realizada uma revisão de consultas de agregação, transações e subconsultas (subqueries). Também foram estudados os comandos DCL (Data Control Language), utilizados para controlar usuários e permissões de acesso ao banco de dados.

Foram trabalhadas funções de agregação, como COUNT e AVG, agrupamento de resultados com GROUP BY, ordenação com ORDER BY e comandos de controle de transações, como START TRANSACTION, COMMIT e ROLLBACK. Também foram apresentados os comandos CREATE USER, GRANT, REVOKE e SHOW GRANTS.

## 📝 Atividades

Foram realizados exercícios envolvendo a quantidade de veículos vendidos por vendedor, identificação de veículos com valores acima da média, funcionários com salários abaixo ou acima da média e total de funcionários por cargo.

Também foram praticadas transações para atualização e exclusão de registros, utilizando ROLLBACK para desfazer as alterações. Por fim, foram realizados exercícios de criação de usuários e concessão e revogação de permissões de acesso às tabelas do banco de dados.
